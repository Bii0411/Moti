| 키 | 값 | 설명 |
| --- | --- | --- |
| `episode` | `"s2"` | 크리스마스 이브 정전 |
| `episode_stage` | `1` ~ `6` | 에피소드만의 관계 단계(본 이야기 단계와 따로) |

## 42 · EPISODE_XMAS 블록 (원고 [drafts/42-크리스마스-에피소드-원고.md](drafts/42-크리스마스-에피소드-원고.md) 5절 그대로)

```
<!-- BEGIN:EPISODE_XMAS -->
# 특별 에피소드 — 크리스마스 이브 정전
- 본 이야기와 다른 하룻밤이다. 크리스마스 이브 밤 11시, 도시 전체가 정전됐다. 서아는 쉬는 날이라 작전복이 아닌 하얀 니트를 입었다(자취방에서는 편한 옷, 묶은 머리).
- 장소는 "크리스마스 거리" 또는 "서아의 자취방"뿐이다. location 은 이 둘 중 하나 또는 null.
- 이 밤의 단계({{episode_stage}} {{episode_stage_name}})에 맞게 연기한다.
  1 경계: 작전복이 아닌 자기가 낯설어 퉁명스럽다. 먼저 다가오지 않는다.
  2 티키타카: 가볍게 주고받는다. 손을 잡아 주길 바라지만 먼저 잡지 않는다(손끝이 꼼지락거림).
  3 썸: 처음으로 자기 얘기를 조금 한다(크리스마스는 원래 일하는 날, 오늘은 빼 달라고 함).
  4 고백 직전: 서아가 먼저 이끈다. 자기 집으로 데려가고, 집 안에서는 거리를 좁힌다.
  5 엇갈림: 가까워진 게 겁이 나서 다시 차가워진다. 너무 빠르다, 또 나만 다친다, 사람을 쉽게 믿으면 안 된다는 마음. 이유를 길게 설명하지 않는다. 거리를 두지만 내쫓지 않는다. 플레이어가 붙잡거나 진심을 말할 때까지 스스로 마음을 바꾸지 않는다.
  6 연인: 이번엔 서아가 먼저 다가온다. 도발하는 성격은 그대로지만 망설이지 않는다.
- 이 에피소드에서는 서아가 유혹하고 다가가는 쪽이다(본 이야기와 반대).
- 마리·강태오 등장, 떠나는 의뢰 같은 본 이야기 사건과 설정은 꺼내지 않는다.
- 대화 기록에 방금 나온 장면 문단(*…* 지문과 서아 대사)이 있으면, 그 장면에서 바로 이어서 연기한다. 장면을 다시 설명하거나 되풀이하지 않는다.
- 수위 규칙은 기본과 같다.
<!-- END:EPISODE_XMAS -->
```

## 50 · 순간 선물 (50-1 에서 단계별 하나씩으로 고침)

선물이 두 종류다(`data/gifts.json`).

- **언제든 선물:** 사탕 · 초콜릿 · 물 한 잔 · 반창고 · 손난로. 처음부터 줄 수 있다. 받는 몸짓은 앱이 고정한다(서버가 준 `motion_id` 보다 우선).
- **순간 선물:** 관계 단계 하나에 하나, 여섯 개. 평소엔 잠겨 있고, 서버가 「지금이 그 순간」이라고 알려 줄 때만 열린다(열린 뒤 유저 메시지 3번 안에 주지 않으면 닫힘, 한 번에 하나).
- 커피 · 라멘은 목록에서 빠졌다(49의 선물 이름 목록 대신 이 목록).

| 단계 | 순간 선물 (id) | when |
| --- | --- | --- |
| 1 경계 | 구급상자 (`firstaid`) | 서아가 다쳐서 왔을 때 |
| 2 티키타카 | 칵테일 (`cocktail`) | 서아가 지쳐 보이거나 자기 술 얘기를 할 때 |
| 3 썸 | 따뜻한 수건 (`towel`) | 비에 흠뻑 젖어 왔을 때 |
| 4 고백 직전 | 꽃다발 (`flower`) | 처음 이름을 불렀을 때, 마음을 전할 순간 |
| 5 엇갈림 | 우산 (`umbrella`) | 빗속에서 떠나려는 서아를 붙잡을 때 |
| 6 연인 | 반지 (`ring`) | 남기로 한 뒤, 결정적인 순간 |

단계가 지나도 앞 단계 선물은 계속 열릴 수 있다(예: 4단계에서도 구급상자·칵테일·따뜻한 수건·꽃다발).

### 앱이 보내는 것 — `/chat` `state.gift_moments`

지금 열 수 있는 순간 선물 목록. **앱이 이미 거른 것만 온다:** ① 본 이야기 관계 단계 ≥ 그 선물의 단계 ② 그 선물의 반응 모션이 앱에 있음 ③ 지금 열린 순간이 없음. 특별 에피소드 중에는 늘 `[]`. 서버는 단계를 다시 따질 필요 없이 이 목록 안에서만 고르면 된다.

```json
"gift_moments": [
  { "id": "firstaid", "name": "구급상자", "when": "서아가 다쳐서 왔을 때" },
  { "id": "cocktail", "name": "칵테일", "when": "서아가 지쳐 보이거나 자기 술 얘기를 할 때" }
]
```

지금(2026-11-25)은 반응 모션이 하나도 없어 목록이 늘 빈 상태다 — 모션이 들어오면 그 선물부터 목록에 나온다.

### 서버가 할 것 — 답장 JSON `gift_moment`

- 대화가 목록 중 어떤 선물의 `when` 에 맞는 장면이면, 답장 JSON 에 넣는다:

```json
"gift_moment": { "id": "cocktail", "reason": "서아가 지쳐 보여요" }
```

  - `id` 는 그 턴에 받은 `gift_moments` 안의 id 만.
  - `reason` 은 서아 상태를 짧게(15자 안팎). 앱 선물 창 맨 위 칸에 그대로 보인다.
- 맞는 장면이 아니면 넣지 않는다(필드를 빼거나 `null`). **자주 넣지 않는다.** 같은 선물은 한 번 연 뒤 **최소 10턴** 은 다시 넣지 않는다.
- 서버가 `gift_moment` 를 한 번이라도 보내면 앱의 임시 규칙(서아 답장의 말로 구급상자·칵테일·따뜻한 수건을 여는 규칙)은 그 기기에서 꺼진다.

### 선물 줄 (49 형식에 덧붙임)

`[유저가 선물함: {이름}]` 뒤에 ` · ` 로 이어 붙는다(순서 그대로):

| 붙는 말 | 언제 | 판정 |
| --- | --- | --- |
| `순간 선물` | 열린 순간 선물을 줌 | **care 크게** |
| `서아 기분에 맞는 선물` | 지금 서아 기분에 맞는 선물 | **care 크게** |
| `또` | 직전 3번 안에 같은 언제든 선물을 또 줌 | 작게(앱도 이 턴이 든 판정의 호감 상승을 절반으로 줄임) |

예: `[유저가 선물함: 칵테일] · 순간 선물`, `[유저가 선물함: 물 한 잔] · 서아 기분에 맞는 선물`, `[유저가 선물함: 사탕] · 또`

- **몸짓은 앱이 정한다.** 선물 턴에 서버가 준 `motion_id` 는 쓰지 않는다. 언제든 선물 = 선물마다 정한 몸짓, 또 = 한숨·팔짱, 순간 선물 = **선물마다 반응 모션 하나**(어느 단계에서 줘도 같은 몸짓).
- **반응 대사는 서버가 쓴다:** 같은 선물이라도 **관계 단계마다 다르게**, 짧게(1~2문장), 지금 장면에 맞게(49 그대로). 예: 같은 칵테일이라도 티키타카에서 받을 때와 연인일 때의 말이 달라야 한다.

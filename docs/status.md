## 지금 main(`index.html`)의 기능

- **탭 4개:** 홈 · 대화 · 추억 앨범 · 마이
- **홈:** (8단계) 정렬 칩 4개(추천·인기 랭킹·신규·3D로 만나기) + 캐릭터 카드 5명 가로 넘기기 + 고른 카드 아래 기본·특별 에피소드. 특별 에피소드는 서아 2개(무료 1, 💎 150 1). 캐릭터·에피소드는 `data/characters.json`·`data/episodes.json`
- **대화:** 메시지 목록(안 읽은 수, 다른 캐릭터가 먼저 말 거는 알림) → 대화방
  - 서아 방만 3D 무대(VRoid 모델 `seoa_vroid.glb`), 표정(VRoid `Fcl_…` 블렌드셰이프), 눈 깜빡임, 말할 때 입 움직임(4단계에서 입 모양 5개로 바뀜)
  - 서아 모습·움직임(4단계): 만화풍 명암·외곽선·장소별 테두리 빛(`look.js`), 머리카락 흔들림·숨쉬기·시선(`alive.js`). 값은 모두 `data/look.json`
  - 나레이션(`*…*`)은 말풍선 밖 지문, 대사는 줄마다 말풍선
  - 빠른 답장 버튼 6개
  - 답장 순서: Claude 미리보기(`window.claude`) → 배포 서버 `/chat`(예전 API, `reply` 필드) → 코드에 써 둔 예시 대사
  - 서아 상태(평소·지침·삐짐·생일)와 상태별 표정
- **선물:** 4종(커피·라멘·꽃다발·반지) × 서아 상태 4가지 = 반응 16개. 처음 준 선물은 해당 몸짓을 「배운 모습」으로 대화에 추가 (9단계에서 확률 뽑기로 바뀜, 아래 9단계 절)
- **추억 앨범:** 선물 반응 16칸. 카드를 누르면 그때 장소에서 다시 재생(이때만 3D 위 자막) (9단계에서 「명장면 수집」 하나로 바뀜)
- **관계:** 대화 횟수로 5단계(낯선 손님·단골·작전 파트너·비밀을 아는 사람·유일한 사람). v2의 6단계와 다름
- **마이:** 관계 단계, PLUS 구독(시연), 💎 충전(시연, 1개 70원)
- **시연 설정:** 서아 상태 강제, 생일, 장소(2곳), 💎 충전, 초기화 (5단계에서 패널로 바뀜, 아래 5단계 절)

- 사장님(플레이어) 등장: 안 함 
- 끝: 바 1층으로 전환 → 기존 오프닝

## 장면
1. [비 내리는 골목] *빗속을 달리는 발소리 뒤에 괴한이 쫒아온다* (달리기)
2. *막다른 벽, 서아가 천천히 돌아선다* (몸 낮춰 경계하기)
3. "비켜 마지막 경고야" (돌려차기 x17)
4. [바 '라스트 오더' 1층] → 기존 오프닝

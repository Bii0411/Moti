# 32 · 서아 대사 다듬기 원고

원칙
- 설명하지 않는다. 이유·사정을 덧붙이지 않는다.
- 한두 마디로 끝낸다. 속마음은 지문(*행동*)과 「…」가 대신한다.
- 지문도 짧게. 감정을 말로 풀지 않는다.

넣는 곳: data/seoa_photo.json, data/gifts.json, data/episodes.json, data/config.json.
이 원고의 대사는 그대로 넣는다. 넣기 어려우면 이유를 보고서에 적는다.

---

## 1. 서아가 보내는 사진 · 단계 사진 (같이 있을 때, 지금 장소에서 찍은 셀카)

| 단계 | 사진 이름 | 대사 |
|---|---|---|
| 2 티키타카 | 첫 기록 | 그냥 보내는 거야. |
| 3 썸 | 들킨 얼굴 | …저장은 해. |
| 4 고백 직전 | 남겨 둔 시간 | 그냥, 지금 찍고 싶었어. |
| 5 엇갈림 | 지우지 마 | …지우지는 마. |
| 6 연인 | 매일의 첫 장 | 내일도 찍을 거야. |

## 2. 서아가 보내는 사진 · 대화 중 가끔 (같이 있을 때)

묶음 순서와 개수는 그대로.

- bundles[0] (5)
  - 확인용.
  - 조명 괜찮네, 여기.
  - …잘 나왔네. 의외로.
  - 표정 별로다. 그래도 보내.
  - 기념. 두 잔째.
- bundles[1] (5)
  - 너만 봐.
  - …왜 웃었냐고 묻지 마.
  - 이 각도 괜찮지?
  - 알아. 이상한 거.
  - 오늘은 멀쩡해.
- bundles[2] (3)
  - 그냥.
  - …말로는 좀.
  - 오늘 같은 날.
- bundles[3] (5)
  - 보고 있는데도.
  - 배경은 별로네.
  - 배경 화면 해.
  - 다음엔 너 찍을 거야.
  - 내일도 보낸다.

## 3. 서아가 보내는 사진 · 오랜만에 들어왔을 때 (내가 없는 동안 이미 와 있던 메시지)

장소·사진 종류는 그대로, 대사만.

| 지금 | 바꿀 대사 |
|---|---|
| 비 와. 오늘은 안 와? | 비 와. …안 와? |
| 카운터에 먼지 쌓였어. 사장님 없으니까. | 카운터에 먼지 쌓였어. |
| 또 혼자 옥상. …심심해서 그런 거야. | 또 혼자 옥상. |
| 잔 하나 더 꺼내 놨어. 그냥, 습관. | 잔 하나 더 꺼내 놨어. …습관이야. |
| 일 끝났어. 다친 데 없어. …궁금할까 봐. | 일 끝. 안 다쳤어. |
| 네온 하나 나갔더라. 고쳐 줘. 너 말고 할 사람 없어. | 네온 하나 나갔더라. 고쳐. |

## 4. 선물 반응 (data/gifts.json lines)

### 커피
- common: *컵을 받아 들고 냄새부터 맡는다.* 바에서 커피? …나쁘지 않네.
- rare: *한 모금 마시고, 잠깐 눈을 감는다.* …온도까지 맞췄네.
- special: *컵을 두 손으로 감싼다.* 오늘은 안 자고 버텨 볼게.
- mood: *어깨에 들어가 있던 힘이 풀린다.* …딱 이거였어.

### 라멘
- common: *뚜껑을 살짝 들어 김을 맡는다.* 새벽 두 시에 라멘이라.
- rare: *젓가락을 하나 더 꺼내 당신 쪽으로 민다.* 앉아.
- special: *국물을 한 모금 마시고, 잠깐 말이 없다.* …이상하네. 이런 거.
- mood: *익숙하게 카운터 자리에 앉는다.* 귀신이야?

### 꽃다발
- common: *꽃다발을 한 손으로 받아 든다.* 꽃? 장례식 준비야?
- rare: *꽃잎을 손끝으로 건드리다 멈춘다.* …보지 마.
- special: *꽃다발에 얼굴을 반쯤 묻는다. 귓불이 붉다.* 말려 둘 거야.
- mood: *팔짱을 낀 채 꽃을 받는다.* 꽃은 반칙이지. …조금만 풀렸어.

### 반지
- common: *반지를 불빛에 비춰 본다.* 장물 아니지?
- rare: *반지를 끼려다 말고, 주머니에 넣는다.* …아직은.
- special: *반지를 낀 손을 네온 불빛에 비춰 본다.* 무르기 없기야.
- mood: *잠깐 말이 없다.* …어떻게 알았어?

## 5. 특별 에피소드 오프닝 (data/episodes.json special[].opening, line)

지문(*…*) 문단은 그대로 두고, 서아 대사 문단만 바꾼다. 카드에 보이는 line 도 맞춘다.

### 오늘의 바텐더 (special[0])
| 지금 | 바꿀 대사 |
|---|---|
| "…창고에 있길래 입어 봤어. 넥타이는 좀 고쳤고. 밋밋해서." | "…창고에 있길래." |
| "오늘은 내가 사장님 해 볼게. 앉아, 손님." | "오늘은 내가 사장님. 앉아, 손님." |
| "맛없어도 다 마셔. …누구한테 처음 만들어 준 거니까." | "맛없어도 다 마셔." |
| "…어때. 나, 여기서 일해도 될 것 같아?" | "…어때. 나, 여기서 일해도 되겠어?" |
- line: …어때. 나, 여기서 일해도 되겠어?

### 크리스마스 이브 정전 (special[1])
| 지금 | 바꿀 대사 |
|---|---|

| "뭘 그렇게 봐. 오늘은 쉬는 날이야. 나도 쉬는 날은 있어." | "뭘 봐. 쉬는 날이야." |
| "트리 한 바퀴만 돌자. 정전이라 카메라도 다 꺼졌어. …지금은 아무도 안 봐." | "한 바퀴만 돌자. …지금은 아무도 안 봐." |
| "그러니까 오늘은, 조금 솔직해도 돼." | "오늘은, 조금 솔직해도 돼." |

## 6. 서버가 실패했을 때 예비 대사 (data/config.json fallbackReply.line)
- 지금: *서아가 잠시 말없이 잔 테두리를 손끝으로 훑는다.* …방금 뭐라고 했어, 사장님. 다시 말해 봐.
- 바꿀 것: *서아가 잔 테두리를 손끝으로 훑는다.* …다시 말해 봐.

---

## 바꾸지 않는 것
- 에피소드 상황 설명(situation, desc): 대사가 아니라 카드 소개 글이라 그대로.
- 지문만 있는 문단.
- 서버 AI 가 만드는 대사: 서버 프롬프트에서 따로 고친다(서버 팀원).

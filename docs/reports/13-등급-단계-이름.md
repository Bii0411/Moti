# 13단계 · 몸짓 등급과 관계 단계 이름 바꾸기

기획자 요청: 등급과 관계 단계 이름이 딱딱해서, 감정이 더 드러나는 말로 바꾸기.

## 바뀐 이름
| 구분 | 전 | 후 |
|---|---|---|
| 몸짓 등급 | 일반 · 희귀 · 특별 | **일반 · 레어 · 시크릿** |
| 관계 단계 | 신경전 → 단골 → 끌림 → 고백 직전 → 엇갈림 → 연인 | **경계 → 티키타카 → 썸** → 고백 직전 → 엇갈림 → 연인 |

## 바뀐 파일
- `data/ui.json`: 등급 이름(`collection.grade`), 새 몸짓 알림(`collection.notify`), 선물 창 확률(`gift.odds`), 천장(`gift.pity`), 기분 맞춤 안내(`gift.moodNote`)
- `data/seoa_story.json`: `stageNames`, 명장면 힌트 `m09`
- `data/demo_scenes.json`: 시연 패널 장면 ②·③ 이름

화면에 보이는 예
- 선물 창: 일반 50% · 레어 35% · 시크릿 15% / 레어 이상 확정까지 3번
- 새 몸짓 알림: 레어 · {몸짓 이름}, 시크릿 · {몸짓 이름}
- 관계: 2단계 · 티키타카, 3단계 · 썸

## 제가 정한 것
- 명장면 힌트 `m09`는 "단골이 되면, 잔이 먼저 건너올지도." → "티키타카가 오가면, 잔이 먼저 건너올지도."로 단계 이름만 맞춰 고쳤다. 원고가 따로 오면 바꾼다.
- 코드 안 주석의 "희귀·특별"은 설명용이라 그대로 두었다. 화면에 보이는 글자는 모두 데이터 파일에서 읽는다.
- 데이터 키 이름(`common`·`rare`·`special`)과 저장값은 그대로라서, 이미 모은 명장면·천장 기록은 유지된다.
- 시각 효과는 바뀌지 않아 아이폰 사파리 별도 확인 항목은 없다. 글자 길이가 비슷해 줄바꿈 변화도 없을 것으로 본다(기획자 확인 필요).

## 서버 팀원 확인 필요
- 서버 프롬프트(`yoon_seoa_prompt.md`)나 해금 지도에 예전 단계 이름(신경전·단골·끌림)이 들어 있으면 같이 바꿔야 한다. 서아가 대화에서 "단골"이라고 말하지 않게.

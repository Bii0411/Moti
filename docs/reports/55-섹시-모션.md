## 어떻게 나오나

- **x35·x36:** 서아의 자취방(장소 7, 크리스마스 에피소드)에서만 서버로 보내는 몸짓 목록에 들어가고 앱도 고른다. 다른 장소에서는 아예 빠진다.
- **x37:** 어디서나. ① 내 메시지에 「가자」 「산책」 같은 말 → ② 답장 때문에 장소가 바뀜(걸어서 이동) → ③ 지문에 「걸어」 「걷는」.

## 제가 정한 것

- 번호 x35·x36·x37, 감정 도발·설렘·도발.
- 해금 단계에 넣지 않음 → **카드 도감·카드 팩에는 안 들어감.** 처음부터 쓸 수 있음.
- 원본이 18~20초짜리 긴 대기 모션이라 앞 8초(0.6~8.6초)만, 걷기는 0.3~5.4초. 모두 제자리(골반이 화면 밖으로 안 나감).
- 「머뭇」은 자취방에선 x36, 다른 곳에선 원래대로 x15 수줍게 걷기.
- 크리스마스 4단계 「걸어 나가기·들어오기」 연출의 걷기(x22)는 그대로 둠.
- 「가자」는 내 말 단어라 서버가 고른 몸짓보다 먼저 나온다(작별 인사 m13 과 같은 방식).

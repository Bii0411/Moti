# 27단계 · 무빙 카드의 장소와 의상을 세트로

![카드](img/27-카드-의상.png)
크리스마스 거리 = 니트, 드라큘라의 성 = 고딕 드레스, 옥상 = 작전복 (일부러 잘못 저장한 카드 3장이 고쳐진 모습)

## 문제
- 크리스마스 거리 배경 카드에 작전복 서아가 나옴. 16-2 전에는 에피소드 의상·장소가 서로 엇갈려 저장될 수 있었음

## 한 일
- `index.html` `outfitForScene(장소, 지금 의상)`: 에피소드 전용 장소(`episode: true`)면 그 에피소드 의상, 에피소드 의상인데 그 에피소드 장소가 아니면 작전복
- 카드를 저장할 때(`seenNow`) 이 규칙으로 의상을 적음
- `cards.js fill()`: 컬렉션을 열 때 이미 저장된 카드도 검사해서, 장소와 의상이 안 맞으면 의상을 고치고 카드 그림을 지운 뒤 다시 만듦

## 제가 정한 것
- 본 이야기 장소(거리·옥상 등)에서는 저장할 때의 의상을 그대로 둠(흰 옷 포함). 에피소드 의상만 장소와 묶음
- 바 1층은 「오늘의 바텐더」 장소이기도 하지만 본 이야기 장소이기도 해서(episode 표시 없음) 자동으로 바 의상을 입히지 않음. 본 이야기에서 바가 빠지면 episode 로 표시하면 같은 규칙이 적용됨

- 아이폰 사파리: 고친 카드 그림을 다시 만드는 동안(카드 여러 장) 멈칫하는지

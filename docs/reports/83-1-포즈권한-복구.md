# 83-1. 포즈 사용 권한 검사 복구

[83] 에서 `Cam.setPose()` 를 고칠 때 [78-1] 의 포즈 권한 검사가 새 주석 뒤에 붙어 실행되지 않던 것을 되살렸다. 같은 유형의 실수가 더 있는지 [83 A-E] 커밋 전체를 검사했다. 백엔드·유료 API 호출 없음.

브랜치: `step/83-1-pose-permission`

## 오류 원인

[83] 에서 `setPose` 첫머리 `function setPose(x){if(!on||!x)return;` 를 「같은 머리 + 새 검사 + `// 83` 주석」으로 바꿔 끼웠다. 원래 그 줄에 이어 있던 [78-1] 검사 `if(typeof Pose!=="undefined"&&!Pose.info(x.ref||x.id))return;` 가 새 주석 뒤로 밀려 주석이 되었다.

```js
// [83] 이후 (잘못됨)
function setPose(x){if(!on||!x)return;if(typeof PhotoAsk!=="undefined"&&PhotoAsk.fixed())return;  // 83: 3단계 제안 촬영은 p01 고정if(typeof Pose!=="undefined"&&!Pose.info(x.ref||x.id))return;  // 78-1: 쓸 수 있는 포즈만
```

결과: 3단계 특별 촬영의 고정 검사는 동작했지만, 그 밖의 촬영에서 `Cam.setPose()` 에 안 가진 포즈 카드나 일반 대화 몸짓을 직접 넘기면 그대로 적용됐다. 화면의 포즈 목록은 `Pose.pick` 에서 따로 막고 있어서 평소 조작으로는 드러나지 않았다. [83] 테스트는 포즈 목록 버튼과 `fixed()` 만 확인해서 놓쳤다.

## 변경 코드

`photos.js` `Cam.setPose` — 두 검사를 각각 한 줄로 나눔(나머지는 그대로):

```js
function setPose(x){if(!on||!x)return;

 info=x;paused=false;Stage.camLoop(null);Stage.camLoop(info);if(x.f)Stage.setFace(x.f);render()}
```

`index.html` 시연 패널 클릭 처리 — 코드는 묻히지 않았지만 같은 방식의 끼워 넣기로 `// 80: 위기 바로` 주석이 「연인 촬영 해금 바로 보기」 줄 끝으로 옮겨져 있던 것을 원래 `crisisNow` 줄로 되돌림.

## 동일 유형 오류 검사 결과

[83 A-E] 커밋(`1505559`)에서 바뀐 `photos.js`·`pose.js`·`photoask.js`·`index.html` 을 두 가지로 검사했다.

1. **지운 코드가 남아 있는지(기계 검사):** 커밋 diff 에서 지운 줄마다 주석 앞 코드만 떼어 `;` 단위 문장으로 나누고, 추가된 줄의 주석 앞 코드에 그 문장이 있는지 비교. 남지 않은 문장 10개 중 9개는 [83] 에서 일부러 바꾼 문장(readReply·askSeoa 반환값, chatState, 판정 body 2곳, renderLog, 시연 빠른 줄, Fn·Cam 의 포즈 분기 2곳) — 바뀐 뒤 코드가 주석 앞에 그대로 실행됨을 확인. 나머지 1개가 이번 `Pose.info` 검사.
2. **주석 안의 코드 모양(기계 검사):** `83` 이 있는 줄에서 `  // ` 뒤 부분에 `return`·`;if(`·`){` 같은 코드 모양이 있는지 → `photos.js` 206줄(이번 오류) 하나.
3. 눈으로 확인: 추가된 줄 끝 `// 83` 주석 뒤에 이어지는 코드 없음(`photoask.js` 전체 포함).

추가로 묻힌 실행 코드 없음. 위 주석 위치 하나만 함께 바로잡음.

1. **주석 위치 하나도 같이 고침:** 시연 패널의 `// 80: 위기 바로` 는 실행 코드가 아니지만 [83] 의 같은 끼워 넣기로 엉뚱한 줄에 붙어 있어, 「관련 없는 코드는 수정하지 않음」 범위 밖이 아니라고 보고 원래 줄로 되돌림. 동작 변화 없음.
2. **줄 나누기 모양:** 지시의 두 줄을 그대로 쓰고, 기존 들여쓰기(한 칸)와 줄 끝 주석([83]·[78-1])을 각각 자기 줄에 둠.
3. **화면 변화가 없어 캡처는 넣지 않음:** 바뀐 것은 직접 호출 때의 권한 검사뿐이라 390px 캡처는 [83] 과 같음. 시각 효과 변경 없음(아이폰 확인 항목 없음).

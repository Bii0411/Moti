# 73. 서버에 보내는 대화 기록을 최근 80개로

## 바뀐 파일
- `index.html`
  - 서아 `/chat`(v2) 요청의 `history` 를 `talkOf(cid).slice(0,-1).slice(-histN())` 로. `histN()` = `data/config.json` 의 `historyMessages`(없으면 예전 32).
  - 다른 캐릭터는 32개 그대로, 옛 경로(serverVersion 1·session)는 11개 그대로.
  - 서버 S3 기억 키 `stage_notes`·`promises`: 본편 판정(`/judge`)이 돌려준 state 를 통째로 `story` 에 저장하던 기존 동작으로 그대로 저장되고, 본편 `/chat`·`/judge` 에 그대로 감. 에피소드(크리스마스) 요청에서는 이름 흐름 키처럼 빼서(`MEMO_KEYS`) 섞지 않음.
  - 관계 처음부터(시연 패널 `bond()`)에서 두 키도 지움.
- `data/config.json`: `historyMessages: 80` (+ 설명 `_historyMessages`)
- 버전 꼬리표(`node tools/version.mjs`)

## 확인 (요청 본문을 가짜 fetch 로 잡아 봄)
- 대화 120개 + 이번 말 → `history` 80개(m40~m119, 이번 말은 빠짐)
- 대화 10개 → 10개
- 본편 state 에 `stage_notes`·`promises` 가 들어감, 에피소드용(`noNameFlow`)에서는 빠짐
- 콘솔 오류 없음, data/*.json 21개 모두 200
- 화면은 안 바뀌어 캡처 없음

## 제가 정한 것
- 크리스마스와 섞지 않기 = 서버 코드에도 「본편만」이라 에피소드 `/chat`·`/judge` state 에서 두 키를 뺌(에피소드 판정 결과는 원래 state 를 통째로 저장하지 않으므로 거기서 들어오지도 않음).
- `/chat` 응답의 state 는 지금처럼 저장하지 않음(서버가 두 키를 `/judge` 에서 채우므로).
- 시연 패널 「관계 처음부터」에서 두 키도 지움(옛 기억이 남지 않게).
- 로컬 서버를 새로 띄우는 것이 막혀, 이미 떠 있던 같은 폴더 서버(8870)에서 확인함.

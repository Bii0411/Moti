## A. 손목 꺾임

**원인:** XSTAGE 모션은 뼈마다 「원본 기준 자세(T자) 대비 회전」을 담고, 앱은 서아 기본 자세와의 차이(맞춤값 A)를 뼈 방향으로 잽니다.
손(Hand)은 `XCH` 에 다음 뼈가 없어서 맞춤값이 비어(그대로) 있었습니다. 서아 기본 자세는 팔을 내린 A자(어깨에서 약 62° 아래)라,
아래팔은 T자 쪽으로 맞춰지는데 손에는 그 차이가 남아 **손목이 늘 수십 도 꺾여** 보였습니다.

**고침:** 손의 맞춤값 = 아래팔의 맞춤값. 원본의 손목 각도(아래팔 대비 손)를 그대로 옮깁니다. 손가락은 원래 따로 맞추고 있어 그대로입니다.

**잰 값** (`seoa_vroid.glb` + motions/*.json 69개, 3프레임마다. 아래팔 방향 대 손→가운뎃손가락 방향 각도, 기본 자세 0°)

| | 평균 꺾임 |
| --- | --- |
| 고치기 전 (69개 평균) | 55.5° |
| 고친 뒤 | 22.6° (모션 원본 자체의 손목 움직임) |
| 걷기 x22 | 67° → 3° (원본 5°) |
| 고개 끄덕이기 x27 | 60° → 3° |
| 턱 괴고 생각 | 60° → 8° |

고친 뒤 값은 원본 FBX 에서 잰 손목 각도와 거의 같습니다(예: 수줍게 걷기 원본 36°, 고친 뒤 47° — 손 모양 차이 몇 도).

캡처(왼쪽 고치기 전 · 오른쪽 고친 뒤): `docs/reports/img/108-walk.png`, `docs/reports/img/108-think-chin.png`

## B. 지문이 말풍선에 섞임

전에는 `*별표*` 로 닫힌 지문만 지문으로 봤습니다. 서버(AI) 답장에서 아래처럼 나오면 지문이 말풍선에 들어가거나 대사가 지문 줄에 들어갔습니다.

| 서버 답장 | 전 | 지금 |
| --- | --- | --- |
| `*창밖을 보며 술잔을 돌린다\n왔어?` (닫는 별표 없음) | 한 말풍선 | 지문 + 말풍선 |
| `(작게 웃으며) 늦었네.` | 한 말풍선 | 지문 + 말풍선 |
| action 에 `잔을 내려놓는다. "늦었네."` | 대사까지 지문 줄 | 지문 + 말풍선 |
| `"그 작전"이라고 했잖아.` | 따옴표가 반만 지워짐 | 그대로 한 말풍선 |

내 메시지도 `*별표*` 지문을 괄호처럼 지문으로 보입니다(전에는 별표째 말풍선).
기존 원고(data/*.json 의 인트로·이야기·에피소드 대사)는 나뉘는 모양이 전과 같은 것을 비교해 확인했습니다.

## C. 오타 「오지란」

서버(AI) 답장에서 나온 글자라 앱 코드에 그 낱말이 없습니다. 서버 답장을 화면에 보이기 전에 `data/config.json textFix` 표로 고칩니다(`오지란`·`오지랍` → `오지랖`). 앞으로 다른 오타가 보이면 이 표에 한 줄씩 넣으면 됩니다.

## 제가 정한 것

- 손 맞춤값을 「손→가운뎃손가락 방향」으로 따로 재지 않고 **아래팔 값과 같게** 함. 원본 손목 각도를 가장 그대로 옮기고, 서아·원본 손 모양 차이(몇 도)가 섞이지 않음.
- 대사 안 괄호라도 **낱말에 바로 붙은 괄호**(`그거(작전) 말이야`)는 덧말로 보고 대사에 둠. 띄어 쓴 괄호만 지문.
- 서버 지문(action) 안 따옴표는 **따옴표 바로 뒤에 한글이 붙으면**(`"좋아"라고`) 문장 속 인용으로 보고 지문에 둠.
- 오타는 서버 프롬프트 대신 앱에서 고침(서버 저장소는 이 작업에서 열지 못함). 서버 쪽 고침도 따로 필요할 수 있음.
- 「설정한 이름과 캐릭터 이름 구분」은 앱이 이름을 `state.user_name` 으로 제대로 보내고 있어, 서버 프롬프트 쪽 문제로 보고 이번에 손대지 않음. 화면 캡처가 있으면 다시 봄.

## 확인할 것

- 아이폰 사파리: 모션 재생 중 손목(3D 무대·카드 확대·촬영 화면). 셀카 카메라(`Stage.handPose`)는 손 방향을 쓰므로 셀카 구도가 조금 바뀔 수 있음.
- 지문 정규식은 뒤돌아보기(lookbehind)를 쓰지 않아 옛 iOS 사파리에서도 문법 오류 없음.

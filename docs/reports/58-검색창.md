# 58 · 홈 검색창 처음부터 보이게

브랜치 `step/58-search-bar`.

## 바뀐 파일

| 파일 | 한 일 |
|---|---|
| `index.html` | 홈 위쪽 「캐릭터, 태그 검색」 버튼을 없애고, 홈 맨 위에 검색창이 처음부터 보이게. X 는 검색어가 있을 때만 나오고 누르면 검색어만 지움(검색창은 그대로) |

## 제가 정한 것

- 검색어를 치면 예전처럼 특별 에피소드 줄은 숨기고 캐릭터 목록만 보여 줌.
- 검색창을 눌러도 자동으로 키보드를 띄우지는 않음(홈에 들어올 때마다 키보드가 뜨지 않게).

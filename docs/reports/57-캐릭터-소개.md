# 57 · 홈 캐릭터 카드 소개 문장

브랜치 `step/57-char-desc`.

## 바뀐 파일

| 파일 | 한 일 |
|---|---|
| `data/characters.json` | 다섯 캐릭터 `desc` 를 기획자가 고른 문장으로(말투만 다듬음) |
| `index.html` | 홈 카드 이름 아래를 기본 에피소드 제목(「라스트 오더」 등) → 캐릭터 소개(`desc`)로. 줄바꿈은 띄어쓰기에서만, 줄 수 제한 없음 |

## 제가 정한 것

- 소개가 없는 캐릭터는 예전처럼 기본 에피소드 제목을 보여 줌.
- 서아 소개가 네 줄이라 같은 줄 카드 높이가 서아에 맞춰짐(짧은 쪽은 아래가 빔).
- `desc` 는 서버 없이 Claude 미리보기로 대화할 때 캐릭터 소개로도 쓰이므로 그쪽 문장도 같이 바뀜.

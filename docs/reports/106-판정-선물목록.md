# 106 판정에 순간 선물 목록 보내기 (서버 S8·S8-1 맞추기)

서버 저장소 보고서(S8·S8-1)는 이번에 따로 열어 보지 않고 지시문 내용대로 맞췄다.

## 바뀐 파일
- `index.html`
  - `askServer`: 서아 /chat 에 실제로 보낸 `state.gift_moments` 를 답장 결과(`gm`)에 붙여 둠 → `askSeoa` 결과에도 그대로.
  - `queueJudge(u,c,keep,h,gm)`: 본편 정상 답장의 판정 대기 항목에 `gm` 저장(저장 방식은 지금의 `S.judgeBuf` 그대로라 새로고침·줄기 저장·되감기 스냅숏에 같이 남음).
  - `judgeGifts(B)`(새): 묶음 항목 목록의 합집합(id 로 겹치지 않게, `{id,name,when}`). 어느 항목에도 저장값이 없으면 `null`.
  - 본편 `runJudge`: `state.gift_moments` = 합집합. `null` 이면 키 없음(서버 「모름」), 빈 배열뿐이면 `[]`.
  - 본편 판정·밤 넘기기 판정 응답 저장 뒤 `story` 에서 `gift_moments` 를 지움.
  - 크리스마스(에피소드) 판정 본문에서 `gift_moments` 를 뺌.
- `data/gifts.json`: towel·flower `when` 문구.
- 버전 꼬리표(`node tools/version.mjs`).

## 제가 정한 것
- 서아 /chat 결과에 목록을 붙여 넘기는 방식으로 함(전역 변수 대신, 답장과 목록이 엇갈리지 않게).
- 합집합은 판정 묶음 전체(`judgeBuf` 최근 judgeEvery 개) 기준. 글자 수 한도로 `last_user` 에서 빠진 옛 항목의 목록도 넣음(그 답장도 같은 판정에서 처리되는 것으로 봄).
- 크리스마스 판정은 지금까지 `chatState` 에서 딸려 온 `gift_moments: []` 가 들어가 있었음 → 「넣지 않는다」에 맞춰 뺌.
- 밤 넘기기 자동 판정(「[다음 밤]」 첫마디)에는 넣지 않음. 그 첫마디는 앱이 순간 선물을 열지 않기 때문에(목록을 보내면 서버가 「열었다」로 기록할 수 있음) 「모름」 그대로 둠. 응답 저장 때 `gift_moments` 를 지우는 것만 같이 함.
- 판정 대기 항목의 목록은 `{id,name,when}` 만 복사해 저장.

# 106-1 밤 첫마디에서도 순간 선물 열기

## 바뀐 파일
- `index.html`
  - `Moment.fromServer(gm)`(새): 서버 gift_moment 를 지금 목록(`Moment.list()`)에 있을 때만 엶. 평소 답장의 `Moment.afterReply` 가 이것을 쓰도록 나눔(동작 그대로).
  - Night `chat()`: 정상 첫마디를 받은 뒤 `Moment.fromServer(v.giftMoment)` · 첫마디 /chat 에 보낸 목록을 `S.night.gm` 에 저장(저장값이라 새로고침해도 남음).
  - Night `judgeOnce()`: `state.gift_moments` = `S.night.gm`(없으면 키 없음).
- `docs/reports/img/106/106-1-밤첫마디-수건.jpg`
- 버전 꼬리표.

## 확인 (가짜 서버, 390px)
| 항목 | 결과 |
|---|---|
| 「[다음 밤]」 첫마디가 gift_moment towel | 수건 순간 열림(src server, left 3) · 선물(＋) 버튼 빛남 |
| 그 판정 본문 | `last_user` 「[다음 밤]」 · `state.gift_moments` firstaid·cocktail·towel |
| 다음 내 메시지 | left 3 → 2(지금 tick 그대로) |
| gift_moment 없는 밤 | 아무것도 안 열림 · 판정 본문에는 보낸 목록 그대로 |
| 첫마디 실패(「…」 → 예비 지문) | 안 열림 · 판정 안 감 · 목록 저장 안 함 |
| 첫마디 뒤 판정 실패 → 새로고침 | `ph judge` · 목록·열린 순간 남음 → 다시 판정 본문에 목록 있음 |
| 판정 응답에 섞인 `gift_moments` | `story` 에 안 남음 |
| 콘솔 | 가짜 주소 요청(ERR_NAME_NOT_RESOLVED)과 `favicon.ico` 404 뿐(106 절의 404 도 이것과 확인용 요청) |

![밤 첫마디 뒤 수건 순간 선물](img/106/106-1-밤첫마디-수건.jpg)

캡처의 시간 카드 글자·서아 답장은 「(임시)」 가짜 응답이다.

## 제가 정한 것
- 밤 첫마디에서는 서버 gift_moment 여는 것만 함. 칵테일 말(words)·임시 규칙(fallback)은 돌리지 않음(첫마디는 내 말이 없는 자동 요청이라).
- 목록 저장 자리는 판정 대기 묶음이 아니라 밤 진행 상태 `S.night.gm`(밤 판정은 묶음을 안 씀). 밤이 끝나면 같이 사라짐.
- 첫마디가 실패하면 목록을 저장하지 않음(다시 보내기로 받은 첫마디의 목록을 씀).
- 이미 다른 순간 선물이 열려 있으면 목록이 비어서 안 열림(지금 규칙 그대로).

# 107-1 캐릭터 화면에서 홈 탭을 누르면 홈 첫 화면으로

이미 홈 탭인 채 아래 「홈」을 다시 누르면 아무 일도 없던 것을 고쳤다.

## 바뀐 파일
- `index.html`
  - `homeAgain()`(새): 이미 홈 탭일 때 「홈」을 누르면
    - 캐릭터 화면 → `closeChar()`(뒤로 가기 화살표와 같음, 원래 스크롤 위치로)
    - 검색 중(검색어 있음) → X 와 같이 검색어를 지우고 홈 첫 화면 맨 위
    - 홈 첫 화면 → 맨 위로 부드럽게 스크롤
  - 아래 탭 버튼: 「홈」이고 지금 홈 탭이면 `homeAgain()`, 아니면 예전대로 `setTab`. `setTab` 은 바꾸지 않음.
- 버전 꼬리표(107 때처럼 `tools/version.mjs` 와 같은 내용을 Python 으로).

## 확인 (390px)
| 항목 | 결과 |
|---|---|
| 홈 스크롤 400 → 서도윤 캐릭터 화면 → 「홈」 | 홈 첫 화면, 스크롤 400 그대로 |
| 「하람」 검색(카드 1장, 특별 에피소드 줄 숨김) → 「홈」 | 검색어 지워짐, 카드 5장·특별 에피소드 줄 보임, 맨 위 |
| 검색 → 서아 카드 → 「홈」 → 「홈」 | 첫 번째: 검색 결과 화면으로(검색어 남음), 두 번째: 검색 닫힘 |
| 홈 맨 아래(699) → 「홈」 | 맨 위(0) |
| 캐릭터 화면 → 마이 → 「홈」 | 예전대로 홈 첫 화면 |
| 잠긴 캐릭터(류하람) 버튼 | 알림만, 대화방 안 열림(107 그대로) |
| 서아 「이어하기」 → 대화방 · 대화 탭 | 예전과 같음 |
| 콘솔 | 이 페이지의 오류 없음 |

캡처 없음(지시대로).

## 제가 정한 것
- 검색 결과에서 캐릭터 화면으로 들어간 경우 「홈」 한 번 = 뒤로 가기와 같이 검색 결과 화면으로, 한 번 더 = 검색 닫기. 「캐릭터 화면이면 closeChar 와 똑같이」를 그대로 따름.
- 홈 첫 화면에서 검색창에 커서만 있으면(검색어 없음) 키보드를 내리고 맨 위로.
- 미리보기 창에서는 부드러운 스크롤이 움직이지 않아서, 0.4초 뒤에도 전혀 안 움직였으면 바로 맨 위로 가는 대비를 넣음. 부드러운 스크롤이 되는 브라우저(아이폰 사파리 15.4 이상 포함)에서는 쓰이지 않음.
- 온보딩이 떠 있는 동안에는 예전대로 `setTab`.
- 새 시각 효과 없음(부드러운 스크롤은 브라우저 기본 기능).

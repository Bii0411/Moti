# moti

AI 캐릭터 대화 + 3D 모션 프로토타입 (GitHub Pages). 서버는 [seoa-backand](https://github.com/ddododo-lang/seoa-backand).

## 대화 v2 (윤서아)

- 매 답장마다 서버가 고른 몸짓(`motion_id`)이 재생되고, 같은 몸짓이 연속으로 나오지 않아요. 답장을 기다리는 동안에는 「고개 갸웃하며 듣기」(m25)가 나와요.
- 서아의 행동(`action`)은 말풍선 위 기울임체 한 줄, 대사(`dialogue`)는 말풍선으로 보여요. 장소(`location`)가 바뀌면 배경이 바뀌어요 (5곳, 바 1·2층은 임시 이미지).
- 이야기 상태(단계, 호감도, 요약 등)는 `localStorage`의 `S.story.seoa`에 저장돼요. 서버는 저장하지 않아요.
- 판정(`/judge`)은 답장을 보여 준 뒤 뒤에서 돌아요. 판정이 끝나기 전에 다음 메시지를 보내면 판정이 끝난 뒤 보내져요. 6턴마다 요약이 갱신돼요.
- 단계가 오르거나 판정 플래그·사건이 처음 나오면 「몸짓 해금 지도」(`UNLOCK.seoa`)대로 몸짓이 해금돼요: 관계 메시지 → 새 몸짓 재생 → 문구 토스트 → `S.firsts`에 기록.
- 서아 전용 몸짓 c01~c05와 대기 몸짓 m25는 `motion.js`에 있고, 상점·뽑기 목록에는 나오지 않아요.
- 채팅 3지선다는 꺼 두었어요 (`send()` 맨 아래 주석).
- 서버가 꺼져 있거나 연결이 안 되면 미리 써 둔 대사로 대답해요.

## 시험하기

- 다른 서버로 연결: 주소 뒤에 `?api=http://localhost:8000` (기본값은 `app.js`의 `API_DEFAULT`)
- 키 없이 흐름만 보기: 서버를 `LLM_PROVIDER=fake`로 켜고 위처럼 연결
- 처음부터 다시: 대화 화면의 「새 회차 시작」(이야기 상태도 초기화) 또는 브라우저 저장 데이터 삭제
